# dweilrobo

DIY autonomous floor-mopping robot: ESP32 for real-time control, home server for mapping and planning.

- `docs/01-engineering-study.md` — engineering study (architecture, sensors, power, layout, costs, open questions)
- `cad/layout.py` — parametric layout and weight/traction checks (`python3 cad/layout.py`, exits non-zero on failure)
- `cad/layout_top.svg` — generated top view
